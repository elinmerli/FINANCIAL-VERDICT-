
# THE MONETARY ARCHIVE

A Southern Gothic financial statistics dashboard.

## Design
- Southern Gothic aesthetic
- Black, rust red and antique gold palette
- Georgia and Cormorant Garamond typography
- Responsive desktop dashboard
- Two-column layout

## Features

### Inflation Calculator
- Initial capital
- Annual inflation rate
- Calculation period
- Real purchasing power
- Percentage of lost purchasing power

### Economic Statistics
- NBP exchange rates
- NBP gold prices
- Federal Reserve data (future integration)
- Polish CPI (future integration)

### Charts
- Purchasing power over time
- Dynamic chart updates
- Automatic recalculation

## Data Sources

- NBP API: https://api.nbp.pl/
- FRED: https://fred.stlouisfed.org/
- GUS: https://stat.gov.pl/

## Installation

1. Upload all three files to the root of your GitHub repository.
2. Open Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select main and root directory.
6. Save.

## Important

GitHub Pages supports static websites.

NBP data is requested directly from its public API.
FRED and GUS integrations require additional configuration.

The calculator uses a constant annual inflation assumption.
It is an illustrative calculation, not a financial forecast.
