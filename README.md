
# THE MONETARY ARCHIVE

International financial and economic information portal.

## Files

- index.html — website entry point
- styles.css — visual design
- data.js — public financial data sources
- script.js — shared formatting and chart functions
- globe.js — interactive 3D globe
- app.js — navigation and page logic
- README.md — project instructions

## Installation

1. Keep all seven files in the same folder.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click index.html.
5. Select Open with Live Server.
6. Wait for data providers to respond.

Do not open the page using file://.

## Data providers

- Frankfurter — currency reference rates
- Narodowy Bank Polski — gold prices
- CoinPaprika — Bitcoin information
- World Bank — economic indicators
- World Atlas — country boundaries
- Globe.gl — 3D globe

## Important

Some providers may temporarily be unavailable or limit requests.

Currency rates are reference rates, not live trading quotes.

Stock and crypto exchange entries are directories, not live exchange connections.

Unavailable observations are not replaced with invented numbers.
